# 小红书笔记模板

## 📝 标题公式（选择适合的）

### 震惊型：
- 「震惊！[事件核心]竟然[出人意料的结果]」
- 「[数字]个人看完都惊了！[话题]」

### 干货型：
- 「[数字]分钟看懂[话题]，全网最全解析」
- 「独家｜[话题]全梳理，你想知道的都在这」

### 情感型：
- 「看完这个[视频/故事]，我哭了」
- 「[人物]做了这件事，全网泪崩」

### 互动型：
- 「如果是你，你会怎么选？[话题]」
- 「你们觉得[话题]能[预测/期望]吗？」

---

## 📝 正文结构

```
【开头 - 引发好奇（2行）】
一句话点明核心爆点 + 情绪表情

【背景介绍 - 谁什么时候做了什么（3-5行）】
用小红书常用emoji标记要点
📌 或者 ✅ 列出关键信息

【核心内容 - 最吸引人的部分（5-10行）】
1️⃣ 第一个要点
2️⃣ 第二个要点
...
数字序号+简短描述

【个人感受/评价（2-3行）】
加入主观看法，引发共鸣

【互动引导 - 结尾（1-2行）】
提一个问题，引导评论
"你们怎么看？""评论区聊聊！""你会怎么选？"

【标签区（10-15个）】
#主题词 #细分词 #热点词 #信息差 #平台推荐词
```

---

## 📝 配图规范

### 封面图（第1张）：
- 核心人物/场景 + 大字标题
- 用Canva/醒图制作
- 比例：3:4（竖版）
- 字体要大、对比色强
- 加"独家""震惊""全网"等标签

### 后续图片（第2-9张）：
- 按时间线或要点逐张展示
- 每张图配2-3行文字说明
- 最后一张图放"关注我"引导
- 翻译外语截图时加中文注释
