# 抖音视频模板

## 🎬 视频类型及模板

### 类型A：图文快剪（最适合信息差内容）
```
时长：30-60秒
画面：新闻截图+视频片段+字幕
配音：解说口播（可用AI配音）
BGM：节奏感强的背景音乐
字幕：全程中文字幕（大号白色描边）
```

### 类型B：口播解说
```
时长：30-60秒
画面：真人出镜+画中画素材
配音：真人口播
BGM：轻柔背景音
字幕：全程字幕+关键词特效
```

### 类型C：盘点/排行榜
```
时长：45-90秒
画面：多素材快速切换
配音：节奏紧凑的解说
BGM：紧张感配乐
字幕：大号数字排名
```

### 类型D：反应/评论类
```
时长：30-45秒
画面：原始视频+反应截图
配音：画外音评论
BGM：搞笑/震惊音效
字幕：翻译+评论
```

## 🎬 视频脚本结构

```
【开头 - 前3秒 - 黄金钩子】
★ 最重要！决定用户是否继续看
方法1：直接抛出最震撼的画面
方法2：提一个勾人的问题
方法3：用数字制造冲击 "96000人点赞的视频"
方法4：反预期 "你绝对想不到……"

【正文 - 中间20-40秒 - 信息密度要高】
★ 每5-8秒一个信息点
★ 画面不断切换，保持新鲜感
★ 字幕始终可见
★ 配音语速略快

【结尾 - 最后5-8秒 - 行动号召】
★ 问一个问题（引导评论）
★ "关注我"（引导关注）
★ 预告下期内容（引导期待）
```

---

## 🎬 字幕规范

```
字体：思源黑体/方正兰亭
大小：大号（手机竖屏下清晰可见）
颜色：白色+黑色描边
位置：画面中下方1/3处
特效：关键词放大、变色、抖动
```

## 🎬 标签策略

```
必选标签（每次都用）：
#信息差 #欧美热点 #全球热搜

话题标签（根据内容选）：
#明星 #科技 #体育 #娱乐 #国际新闻

长尾标签（具体话题）：
#卡戴珊 #超级碗 #冬奥会 等

流量标签：
#热点 #爆款 #涨粉 #必看
```
